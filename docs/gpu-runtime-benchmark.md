# GPT-SoVITS GPU 真实验收记录

结果：通过

## 验收环境

- GPU：NVIDIA GeForce RTX 3060 Laptop GPU，6144 MiB
- 运行模式：CUDA FP16，batch size 1
- 音色：本地已授权的 `haibara-jp`，GPT-SoVITS `v2Pro`
- 参考音频：32 kHz、16-bit、单声道 PCM WAV
- GPT-SoVITS：固定提交 `48b1a0169a28582a8984402f82cf438d3bfa6aca`
- 开发运行时、依赖、模型和输出均位于项目数据盘目录 `.runtime-dev/`，未写入 Git

## 原生 Windows 便携运行时实测结果

| 指标 | 结果 |
| --- | ---: |
| sidecar 冷启动 | 6.347 秒 |
| 自定义音色加载 | 25.966 秒 |
| 冷态首个 PCM | 21.007 秒 |
| 冷态整句 | 21.833 秒 |
| 热态短弹幕首个 PCM | 1.564 秒 |
| 热态短弹幕整句 | 1.715 秒 |

| 热态短弹幕输出 | 3.88 秒，248320 bytes |

热态首包低于 3 秒验收上限。为保持该延迟，个性化语音开启期间模型保持热加载；关闭语音或切回系统音色后 sidecar 退出，因此应用自身的空闲 GPU 占用为 0。

## 自动校验

- 两次输出均为有效的 32 kHz、16-bit、单声道 PCM。
- 长试听峰值 28288、RMS 4883.77；热态短弹幕峰值 29456、RMS 4995.84，均通过非静音校验。
- 客户端首帧计时分别为 21.007 秒和 1.564 秒，侧车报告的首帧计时分别为 20.999 秒和 1.543 秒。
- sidecar PID 在关闭请求后退出；随后轮询 `nvidia-smi`，确认该 PID 已不在 GPU 计算进程列表中。
- 验收通过项目的 `GpuRuntimeManager` 启动、认证、加载、流式合成与关闭侧车，并使用项目导入器生成的标准音色包。
- 受授权保护的试听 WAV 与模型留在忽略目录，只提交本性能摘要。
- 音色相似度和主观听感由用户试听判断，不由自动测试代替。

另在 Linux 开发运行时上完成了同一条链路的交叉验证：热态短弹幕首包 1.613 秒、整句 1.744 秒，峰值显存同为 1707 MiB。发布验收以上表的原生 Windows 便携运行时数据为准。

复现入口为 `scripts/test_real_gpu_voice.py`。该测试需要本机 NVIDIA GPU、已准备的独立运行时和用户有权使用的音色素材，不属于普通单元测试。
