BiliLiveTool Windows 便携版使用说明
==================================

请先新建一个独立文件夹，再把压缩包完整解压到该文件夹中运行。

推荐步骤：
1. 新建文件夹，例如 D:\Apps\BiliLiveTool\
2. 将压缩包内的整个 BiliLiveTool-v2.4.0-windows-amd64 文件夹解压出来
3. 双击 BiliLiveTool.exe

程序运行后会在 EXE 所在目录生成 logs\、config.json 等本地文件，因此不要把
BiliLiveTool.exe 单独放在“下载”目录、桌面根目录或其他杂乱目录中运行。

config.json 可能包含账号登录信息，请勿上传、转发或与他人共享整个程序目录。
CPU 运行时和个性化音色请通过软件内的“导入”界面安装，不要手动塞进本目录。
